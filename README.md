# LLM出力に関する戦略的ライセンス対応
本プロジェクトは、完全なフリーライセンスモデルを厳守します。外部から内容確認なくクローンされたデータを一切使用しないことで、法的な曖昧さを最小限に抑えます。
**※本辞書は作成段階や集計時、MIT Licenseと同程度及び、それ以上に利用許諾が緩いデータ以外は、自身の知識から手打ちでデータ統合を行う以外の方法でのマージを禁止しています。**(※1)

この戦略により、本モデルから派生したトークナイザーや重みデータを含む、LLMの推論結果もまた、自由に利用できるライセンスとなります。

したがって、本辞書やコーパス群での、生のコーパスデータやカテゴリ別辞書の作成は、非常に時間のかかる作業となります。

# Strategic Licensing for LLM Outputs
This project strictly adheres to a completely free license model. We minimize legal ambiguity by **not using any externally cloned data without proper content verification.**
**※During the creation and aggregation phases, this dictionary strictly prohibits merging data through any method other than manual integration based on internal knowledge, unless the external data possesses a usage license equivalent to or more permissive than the MIT License.** (※1)

This strategy ensures that the inference results output by LLMs, including the tokenizer and weight data derived from this model, will also be freely licensed.

Consequently, the creation of raw corpus data and categorized dictionaries for this corpus collection is a highly time-consuming process.

If you agree with all of the above, we would greatly appreciate your help with data creation and categorization.
